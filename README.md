# PassKar Campus Connect

You are an elite Product Designer, UI/UX Designer, Brand Designer and Senior Frontend Engineer.

Your goal is to create a COMPLETE production-quality frontend MVP for a startup called PassKar.

This is NOT a hackathon-looking project.

It should look like a real startup that has already raised funding.

====================================================

PROJECT

Name:

PassKar

Tagline:

Pass More Than Things.

Mission:

Nothing valuable should leave campus with a graduating student.

PassKar is an AI-powered Campus Circular Economy platform where students can borrow, exchange, donate, sell and share resources, skills and knowledge within their university instead of letting them become waste.

This project aligns with UN SDG 12 (Responsible Consumption and Production).
